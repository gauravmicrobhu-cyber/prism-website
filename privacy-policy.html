Privacy Policy

This site is a static research publication. It collects very little, and this page explains exactly what.

What This Site Collects

The PRISM website is a static site with no accounts, no login, and no forms currently active. It does not set tracking cookies, run third-party analytics, or collect personal data through the pages themselves. Google Fonts are loaded from Google's servers to render page typography, which may involve a standard font-request connection to Google — no PRISM-specific data is transmitted through this.

Hosting

This site is hosted on GitHub Pages. GitHub may log standard server access information (such as IP address and browser type) as part of its own infrastructure operations — see GitHub's own privacy statement for details on that layer.

Future Changes

If PRISM adds a contact form, newsletter, or other data-collecting feature in the future, this policy will be updated accordingly before that feature goes live.

Status

This is a general-purpose policy for a static site with no data collection. If PRISM's practices change, or if a formal legal review is needed for your jurisdiction, this page should be revised accordingly.
